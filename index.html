  • Crear la rama personal

Pasos para practicar

  1. Hacer el fork del repositorio y clonarlo.
  2. Crear una rama propia: git checkout -b mi-rama
  3. Editar este archivo (agregar tu nombre y una tarea).
  4. Confirmar los cambios: git add . y git commit -m "mensaje"
  5. Subir la rama: git push origin mi-rama
  6. Crear el pull request en GitHub.
  7. Revisar el pull request de un compañero y fusionarlo.
  8. Sincronizar con el repositorio original: git fetch y git merge
